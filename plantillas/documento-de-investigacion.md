# Estructura general de un documento de investigación

Copia esta estructura en tu editor y adapta el orden, los nombres de capítulos y el formato a las reglas de tu programa. Es una guía de contenido.

| Apartado | Qué debe quedar claro |
| --- | --- |
| Portada | Título, autores, director, programa y fecha |
| Resumen, abstract y palabras clave | Problema, datos, método, resultado central y aporte; redactar al cerrar el trabajo |
| Introducción | Contexto, propósito y organización del documento |
| Problema y pregunta | Situación concreta, evidencia, alcance y pregunta verificable |
| Justificación | Relevancia, usuarios, decisiones, aporte y viabilidad |
| Objetivos | Objetivo general y específicos con productos verificables |
| Marco de referencia | Conceptos, antecedentes comparados y oportunidad de aporte |
| Metodología | Enfoque, datos, CRISP-DM adaptado, protocolo, herramientas, ética y límites |
| Desarrollo del proyecto | Una subsección por objetivo: proceso, decisiones, evidencia, interpretación y hallazgos |
| Resultados | Comparaciones, incertidumbre y evidencias que responden los objetivos |
| Discusión | Interpretación en el dominio, contraste con antecedentes, aporte y amenazas a la validez |
| Conclusiones | Respuestas a la pregunta y los objetivos con evidencia verificable |
| Recomendaciones | Acciones viables, límites de uso y trabajo futuro |
| Referencias | Fuentes realmente consultadas, citadas y verificadas |
| Disponibilidad de datos y código | Fuentes, condiciones de acceso, repositorio, versión y reproducción |
| Declaración de uso de IA | Herramienta, propósito, partes asistidas y verificaciones propias |
| Anexos | Bitácora, diccionario, tablas extensas, instrumentos y material suplementario |

## Antes de cerrar

- Usa la [lista de reporte](../guias/lista-de-reporte.md).
- Revisa cada capítulo con los [prompts R1–R13](../prompts/README.md).
- Comprueba que todas las cifras coincidan con tu código y tus tablas.
- En maestría, explica la contribución de investigación y acuerda su evaluación con tu director.
