# Ejemplos de código por tema

Colección de enlaces a cuadernos y proyectos de sus respectivos autores. Explora cómo resolvieron cada paso, comprende el código y adapta las ideas a tus datos. Cita la fuente y revisa su licencia antes de reutilizar contenido.

Los proyectos externos son ejemplos de estudio: no todos usan el mismo protocolo ni garantizan resultados en tus datos. El código externo no se ha ejecutado como parte de esta biblioteca. Algunos recursos compartidos pueden solicitar acceso a su propietario.

## Cómo abrir un cuaderno en Colab

Para una dirección de un archivo `.ipynb` que empieza por `https://github.com/`, reemplaza ese inicio por `https://colab.research.google.com/github/`. Si el enlace lleva a una carpeta, abre primero el archivo `.ipynb`. Revisa rutas, datos y dependencias antes de ejecutar.
