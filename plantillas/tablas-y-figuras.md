# Tablas y figuras para explicar tu proyecto

No es obligatorio ni igual para todos: es un menú con las tablas y figuras que más ayudan a mejorar, explicar y defender un proyecto de analítica. Usa las que tengan sentido para tu proyecto; en tutoría revisamos si falta alguna clave.

| Tabla o figura | Para qué sirve |
| --- | --- |
| **Ficha del dataset y diccionario de datos** | Describir los datos y cada variable |
| **Calidad antes y después del ETL** | Mostrar cuántos datos se perdieron y por qué |
| **Distribución de la variable objetivo y mapa de correlaciones** | Justificar las decisiones de modelado |
| **Variables creadas con su fórmula** | Documentar la ingeniería de características |
| **Espacio de búsqueda e hiperparámetros finales** | Permitir reproducir los modelos |
| **Resultados por modelo con media ± desviación** | Tabla central de resultados |
| **Comparación de modelos por partición** | Mostrar la estabilidad de cada modelo |
| **Ablación con y sin características** | Probar el aporte de las variables creadas |
| **Diagrama de diferencia crítica** | Resumir la comparación estadística |
| **SHAP resumen y dependencia** | Convertir el modelo en hallazgos del dominio |
